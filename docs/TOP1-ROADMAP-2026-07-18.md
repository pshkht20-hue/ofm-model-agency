## 03 · Алгоритм ранжирования (7 факторов, по важности)
1. **Совпадение интента и формата** (job-запрос → листинг вакансий; рычаг: JobPosting-раздел).
2. **Точное вхождение на языке выдачи** (uk-запрос → uk-страница с точной фразой в title, ×2–3).
3. **Свежесть** (даты, ротация; рычаг: авто-ротация дат вакансий).
4. **Полнота покрытия** (PAA/FAQ/подтемы; рычаг: FAQ-schema).
5. **E-E-A-T / доверие** (агентство > «Private person»; рычаг: /cases, отзывы, комплаенс).
6. **Внутренняя перелинковка** (hub-and-spoke на BOFU).
7. **Ссылки — №7 из 7** (в нише почти не решают; сетка Максима — поддержка).

**Действие для любого запроса:** формат выдачи → страница нужного формата на нужном языке с точной фразой → полнота (PAA/FAQ) → свежесть → перелинковка → еженедельный замер → итерация.
