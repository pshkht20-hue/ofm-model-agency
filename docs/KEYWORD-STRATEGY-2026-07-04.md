## Исследование 1: GSC: живые запросы за 90 дней

SUMMARY:

(2) Инфо-кластер «что такое онлифанс» (RU) — самый широкий магнит: /blog/chto-takoe-onlyfans собирает 280 показов по 66 запросам, включая ~50 показов чистых опечаток и сленга (онлифанщица, лнлифанс, онли фанм, онлифанч, онлик), но висит на позиции 15–22 — один апгрейд пиллара поднимет весь хвост. (4) Спрос без предложения: onlyfans calculator (15 показов, поз. 64+), «ии модель для онлифанс» (~16 показов, поз. 36–47, падает на главную), юридична допомога у справах OnlyFans (UK, ~9 показов, поз. 52+), «правила онлифанс», «onlyfans обзор». Гео: USA 382 / RUS 251 / UKR 174 / KAZ+BLR 30 показов — русскоязычный спрос шире Украины.

## Исследование 2: Google Ads: 736 реальных запросов кампании

SUMMARY:
