## Технические уроки замера

- GSC-скрипты запускать из корня репо (относительный путь к сервис-аккаунту), `--page=/...` в Git Bash — только с `MSYS_NO_PATHCONV=1` (иначе MSYS превращает путь в `C:/Program Files/Git/...` и запрос молча пуст).
- hreflang в HTML — атрибут `hrefLang` (camelCase): grep без `-i` не находит.
- Page-level и property-level итоги GSC различаются (~1% клики, до 10% показы); последний день GSC — минус 2 дня; выгрузка запросов с rowLimit 2 000 отрезает 0-кликовые строки (ложные «пропавшие запросы»).
