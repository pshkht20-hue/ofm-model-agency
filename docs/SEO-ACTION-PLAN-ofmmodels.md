## 2. Методология (из аудита + Anton Sokolovskiy Marketing)

### Берём и применяем

1. **Кластеризация семантики** — одна страница = один кластер запросов  
2. **Title ≠ H1**, ключ в начале, description с CTA  
3. **Статьи под НЧ-запросы** — основной бесплатный рост без закупки ссылок  
4. **Внутренняя перелинковка** — главная ↔ блог ↔ FAQ ↔ заявка ↔ кейсы  
5. **Google Search Console** — еженедельный контроль показов, CTR, индексации  
6. **Google AI Overviews** — FAQ, прямые ответы в H2/H3, первый абзац = ответ  
7. **Alt/Title изображений** — кейсы, обложки блога  
8. **PageSpeed** — Vercel уже быстрый; мониторить Core Web Vitals в GSC  
9. **Естественные ссылки** — Telegram, Instagram, каталоги, партнёры  
10. **ChatGPT** — только черновик; финал вручную под OnlyFans-нишу  

### Не делаем

- WordPress/Rank Math туториалы (стек Next.js)  
- Агрессивная закупка ссылок и анкоров  
- Google Ads / Facebook Ads (пока блок и модерация ниши)  
- Гонка с Layboard по «работа моделью / вакансии»  
- Ежедневный spam «Запросить индексацию» одних URL
