## 4. Замечания к методике

- Средняя позиция GSC — средневзвешенная по показам; на низких показах (<10) сильно шумит, сравнивать аккуратно.
- Запросы «онлайн работа для девушек», «чатер онлифанс», «онлифанщица» (точная форма) за оба окна показов не имели — это и есть baseline: 0 показов. Появление показов после волны C = прямой эффект.
- UK-версия /uk/blog/chto-takoe-onlyfans висит на позиции ~20–24 при 200+ показах за неделю — главный кандидат на рост от волны C (укр. инфо-ядро).
- Следующий срез снимать теми же окнами (7 дней / 3 дня, лаг GSC ~2 дня) для честного сравнения.
