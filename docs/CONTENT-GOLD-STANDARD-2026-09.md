# 🥇 Золотой стандарт статьи OFM — конституция контента (утверждается 30.08.2026)

> Основа: исследование 6 направлений 30.08 (Google Search Central, Surfer 1M SERP, Princeton GEO-paper, Ahrefs 400M цитат, Semrush 10M ключей, Chartbeat 2B визитов, 5 кейсов роста без ссылок) **+ наши собственные GSC-данные** (реврайт чатер-статьи: CTR ×11 задокументирован). Каждое правило здесь — с доказательством. Действует для ВСЕХ новых статей и рефрешей. Философия-родитель: каждый текст = идеальный рекламный креатив + идеальное СЕО одновременно (память feedback-content-philosophy).

## 0. Главный стратегический вывод из наших данных

**Интент решает больше структуры.** Наши роль/работа-статьи дают CTR 4–6%+ («чатер кто это» 4,31%, «работа моделью» 4,45%, Молдова-гео 16,9%!), а «что такое»-статьи — <1% при любой структуре, потому что на них висит AI Overview и съедает клик. Следствия:
- Приоритет новых статей — **jobs/роль-кластер** (кто это + сколько платят + как стать), инфо-головы — вторым эшелоном.
- «Что такое»-страницы оцениваем по позиции и ассистам, НЕ по CTR — и не мучаем бесконечными реврайтами.
- В сниппет выносим то, чего НЕТ в AI Overview: вилки денег, путь, сроки. Дублировать определение из Overview = 0,7% CTR (доказано на нашем chto-takoe).

## 1. До написания (pre-flight, обязательный)

1. **Интент и формат из топ-3**: смотрим живую выдачу — формат копируем (гайд/листикл/история), контент нет.
2. **Вопрос без ответа**: в 90% выдач есть вопрос читательницы, на который топ-3 не ответили — находим его, секция с ответом = наш дифференциатор.
3. **Орфография ключа из GSC/DataForSEO, не «правильная»**: «чатер» (480/мес), не «чаттер» (0). Проверка формы слова — перед каждым тайтлом.
4. **Место в кластере**: статья пишется только в кластер, где уже есть ранжирование (sequencing), с планом перелинковки: → хаб, → 2–3 соседа, → деньги-страница (/join или вакансия). Кластер добиваем до конца, потом следующий.
5. **10–15 собственных цифр** готовим ДО текста: суммы из наших статистик, сроки, конверсии, анонимные кейсы «модель Х за 2 месяца…». Это главный предиктор оригинальности (Information Gain 62/100 vs 40/100) и наш ров — рерайтеры этого не воспроизведут. Клеймы строго в рамках: $15K–$50K, 20–30% с реинвест-обоснованием (в блоге можно, на вакансиях нет).

## 2. Тайтл и дескрипшен (наша проверенная формула)

- **Роль-статьи**: «[точный ключ]: кто это, сколько платят и как стать» — ≤55–60 знаков. Доказано: CTR ×11.
- **How-to**: число шагов в тайтле («…: 5 шагов и верификация») — CTR ×1,9 доказано.
- **Дескрипшен** — стиль джоб-объявления с конкретикой: «удалённо, можно без опыта, старт за 7–14 дней, заявка анонимна, 18+».
- Описательно, без кликбейта и «шокирующей правды» (Google-критерий + доверие ЦА). Title обещает ровно то, что первый экран даёт.

## 3. Скелет статьи

1. **Answer-first везде**: первое предложение статьи = прямой ответ/определение с ключом. Под КАЖДЫМ H2 первые 40–60 слов — самодостаточный ответ (44% AI-цитат берутся из первой трети страницы; 40–60 слов цитируются без обрезки). Никаких «в современном мире».
2. **Бренд внутри цитируемого блока**: «Агентство OFM платит модели…», не безличное «агентства платят» — цитата в AI Overview должна работать как реклама даже без клика (цитируемые сайты получают +35% CTR).
3. **Двухаудиторное вступление** для роль-статей: «этот разбор для двоих — если ты модель… / если ищешь работу…» (паттерн победителя, две воронки выхода).
4. **H2/H3 = живые вопросы** как их задают («сколько платят чатеру», «безопасно ли это») — из PAA и GSC-хвостов. Заголовки короткие, вариативные, без набивки ключами.
5. **Страхи ЦА — полноценными H2-секциями** в порядке возникновения (анонимность → безопасность → «что скажут» → легальность), спокойным тоном. Не мелким шрифтом в подвале.
6. **Таблицы 2-колоночные, 3–5 строк**: «термин → что значит», «уровень → деньги/мес» (таблицы цитируются ×2,5; наш победитель их имеет).
7. **FAQ: 4–6 вопросов** (НЕ 20 — доказано на нашем анти-примере) дословно из живых запросов, включая неудобные («отзывы почему разные?», «это развод?», «законно ли в Украине?»). Ответ — 2–4 самодостаточных предложения с цифрой.
8. **Объём 15–25K знаков** (8–12 мин). Полнота покрытия важнее длины: закрыли ~75% аспектов темы — стоп, воду не льём.
9. **Болд 2–5 на экран**: термины, суммы, сроки — для сканирующей мобильной читательницы.
10. **E-E-A-T первым лицом**: «мы выводили на верификацию 200+ страниц», «в нашей практике Paxum одобряют за N дней» — опыт вместо пересказа. Это и есть анти-википедия.
11. **Семантические вариации** вместо повторов точного ключа: «агентство» → «команда, которая ведёт страницу» → «менеджмент».

## 4. Воронка в Telegram (встроена в текст, не поперёк него)

1. **3 CTA одной цели на глубинах ~25% / ~60% / конец** — средний скролл 27–50%, единственный CTA в конце видит меньшинство. CTA ставится ПОСЛЕ ответа на вопрос секции — как следующий шаг, не как стена.
2. **Формат — inline/контекстный блок** (+121% vs сайдбар), никаких баннеров.
3. **Двухуровневость**: середина — мягкий шаг («канал t.me/ofmmAgency — кейсы и вакансии» для сомневающихся), конец + sticky — прямой («написать менеджеру»).
4. **Текст CTA = обещание шага + снятие обязательств**: «Написать менеджеру — расскажет, с чего начать, без обязательств». Не «Подробнее».
5. **Deep-link t.me без промежуточных форм** (формы теряют до 80% на мобильных).
6. **Соцдоказательство вплотную к CTA**: цитата модели с цифрой (в разрешённой вилке) прямо перед кнопкой (+15–34%).
7. **Микро-обязательство перед главным CTA**: мост на калькулятор («проверь свою вилку за 1 минуту») — калькуляторы дают 20–30% самых горячих лидов; результат калькулятора уже ведёт в TG.
8. **7 контекстных nav-блоков** (паттерн нашего победителя): после каждого смыслового раздела — переход на следующий шаг воронки (вакансия/калькулятор/соседняя статья). Не копить ссылки в футере.
9. **«История Кати» — механизм, не украшение**: нарратив подавляет счётчик возражений (мета-анализ Springer 2025). Смешанный формат: живая история + цифры и шаги внутри неё. Консистентность с нашими клеймами обязательна.

## 5. Картинки (стандарт после пополнения fal.ai)

1. **4–8 оригинальных изображений** на статью 15–25K знаков (~1 на 300–500 слов), по одной на экран скролла. Сток — ЗАПРЕЩЁН для смысловых картинок (Google отдаёт кредит фотобанку — доказано экспериментом и ликом 2024; ЦА мгновенно считывает шаблон).
2. **Типы**: фирменная графика fal.ai (космос/неон/силуэты — стиль-гайд бренда), скриншоты статистики с водяным знаком (наш актив из кейсов!), инфографика с цифрами (единственный тип, собирающий бэклинки; Google читает текст внутри картинок).
3. **AI-«фото моделей» — ЗАПРЕЩЕНО**: только реальные с согласия или ничего. AI — для схем и графики.
4. **Hero** — после вводного абзаца, через next/image с `priority`, ≤200KB. Остальные — lazy (по умолчанию), ≤100KB, всегда с width/height.
5. **Alt** — описательная фраза до 125 знаков на языке версии страницы, ключ только если органичен; декоративным — alt="".
6. **Имена файлов**: латиница-через-дефис с ключом (chatter-onlyfans-income-chart.webp), единые для всех hreflang-версий, после индексации НЕ переименовывать.
7. **Captions под смысловыми картинками = микро-продажа**: «Статистика модели за 3-й месяц с командой», не «Рис. 1».
8. Раз в месяц: GSC → Search type: Image (image-трафик приходит через 4–6 недель).

## 6. Видео (когда уместно)

1. Только через **facade** (`@next/third-parties` YouTubeEmbed / lite-youtube-embed, youtube-nocookie.com). Голый iframe запрещён — минус 20–40 пунктов PageSpeed.
2. Только когда видео реально дополняет статью по её ключу; вокруг — 2–3 предложения контекста. Страница обязана жить и без видео.
3. Приоритет — свои видео (когда появится канал; помним: OnlyFans в своих видео не называем). Чужие — только нейтральные (продакшн, финграмотность), БЕЗ разоблачений/скама/негатива об агентствах.
4. VideoObject-схема — только своим видео.

## 7. Схемы и техчасть

- **Одна релевантная схема** (BlogPosting; + FAQPage если есть FAQ). Стопка типов коррелирует с худшими позициями. Схема — гигиена, НЕ рычаг AI-цитат (причинный тест Ahrefs: ноль эффекта).
- llms.txt НЕ делаем (краулеры не читают). Вместо этого — проверить robots.txt: GPTBot, OAI-SearchBot, ClaudeBot, PerplexityBot, Google-Extended разрешены.
- AI-черновик допустим (нулевая корреляция с позициями), но ранжирует слой, которого у LLM нет: наши цифры + первое лицо + humanize-пас (снять AI-паттерны: «в современном мире», правило трёх, пустые обобщения).

## 8. После публикации (ритуалы)

1. Indexing API + IndexNow сразу; список владельцу для ручного GSC.
2. Входящие интерлинки: хаб + 2–3 соседа ссылаются НА новую статью в тот же деплой (эффект перелинковки — 3 недели, самый быстрый рычаг).
3. GA4-разметка CTA-кликов с позицией (intro/mid/end/sticky/calc) — решения по своим данным.
4. **Комментарий-эксперимент в коде** при каждом реврайте: дата, показы/клики/позиция ДО, гипотеза, источник приёма. (Наша практика, которая доказала CTR ×11 — продолжаем.)
5. **Рефреш каждые 2–4 месяца** по существу (новые цифры/вопросы) — удваивает шанс топ-10 за 30 дней. Дату менять ТОЛЬКО при реальном изменении. Нетронутые статьи теряют ~2 позиции в год.
6. Раз в месяц — ручная проверка цитируемости в AI Overview/Perplexity по 10–15 ключам + сегмент рефералов chatgpt.com/perplexity.ai в GA4.
