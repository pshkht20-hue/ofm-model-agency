## 2) Метод keyword-карты (seed → страница)

Цель — карта **ключ→страница**, где каждая целевая страница владеет одним кластером, и ты находишь **ЦА-интент** (люди, которые хотят результат), а не brand/B2B. Инсайт из GSC: OFM ранжировался по B2B-запросам, **не** по recruitment-интенту, который реально печатает ЦА — этот метод исправляет.

**Шаг 1 — Сиды (RU-база).** Три бакета:
- *Outcome/aspiration* (что хочет кандидатка): «работа из дома девушке», «удалённый заработок для девушек», «как зарабатывать в интернете» — **это недообслуженный ЦА-слой.**
- *Category/service*: «модельное агентство онлайн», «менеджмент [ниша]».
- *Objection/safety*: «это безопасно», «развод или нет», «отзывы».

**Шаг 2 — Расширение.** Сначала бесплатные поверхности (DIY-with-AI): Google/YouTube автоподсказки, «People Also Ask», answerthepublic-стиль, язык Telegram/форумов, + LLM-проход на 200–400 фраз/бакет. (Ты уже делал 181-ключевое расширение для сборщика — та же техника, другой интент.)

**Шаг 3 — Кластеризация по SERP, не по строке.** Группируй фразы, которые дают *те же топ-10 URL* → одна страница. Общий SERP = **одна страница** (анти-каннибализация). Самый высокорычажный шаг.

**Шаг 4 — Интент → тип страницы:**
| Интент | Тип |
|---|---|
| Инфо «как/что/безопасно» | Пост/пиллар |
| Сравнение «vs/какое агентство» | Пиллар + FAQ |
| Aspirational-результат | Home/Services/гео |
| Локальный «[город]+работа» | **Скрытый город-лендинг** |
| Данные «зарплата/статистика» | Research-отчёт (Dataset) |

**Шаг 5 — Оверлеи локалей.** Карта строится **на RU** (defaultLocale). Затем: **uk** = почти полный оверлей (второй рынок, приоритет Украины — весь спайн); **en/es** = **гейтед-оверлей** — переводим страницу только когда перевод реально есть (hreflang не смотрит в 404). Начать с 2 сильнейших пилларов.

**Шаг 6 — ЦА-guardrail.** Для каждого кластера: *«Печатающий это хочет стать кандидаткой — или это бизнес/исследователь?»* B2B-only кластеры убить/депрайоритизировать, если они не кормят research/ссылочный ассет. Валидировать реальными данными — выгрузка Google Ads terms + GSC как ground truth спроса.

**Артефакт:** один лист — `ключ | объём/мес (оценка) | интент | кластер | целевая страница | локали | статус`. Это и есть твой контент-бэклог.

## 3) Контент на первые 90 дней (конкретно)

Ритм важнее объёма, но молодому сайту нужна поверхность для кластеризации внутренних ссылок. Цель: **~20 URL к 90 дню**, RU-база, uk оверлей на спайне.

**Недели 0–2 (скелет, ru+uk):** Home, About, Services, FAQ, blog hub, 1 legal-набор. Постов пока нет — сначала правильные рамка + schema + sitemap + `NEXT_PUBLIC_SITE_URL`.

**Недели 3–12 — 5 пилларов + 12–15 поддерживающих (2/нед):**

*Пиллары (длинные, HowTo/FAQ schema, хабы внутренних ссылок):*
1. `start`: «Как начать работу в [нише] — полный гайд» (RU+UK, затем EN/ES)
2. `money`: «Сколько реально можно заработать — честные диапазоны» (RU+UK) — кормит research-отчёт
3. `safety`: «Это безопасно? Анонимность, договоры, красные флаги» (RU+UK)
4. `agency`: «Как выбрать агентство / что делает хорошее» (RU+UK)
5. `marketing`: «Как работа устроена день-в-день» (RU)

*Поддерживающие (кластер вокруг пилларов, каждый линкует вверх на пиллар + 2 соседей):* 3 под `start` (первый день, инструменты, ошибки), 3 под `money` (налоги-база, выплаты, мифы дохода), 3 под `safety` (приватность, признаки скама, выход), 3 под `agency` (вопросы, условия договора, отзывы), 2 под `marketing`.

**Порядок локалей:** RU всё → UK оверлей на 5 пилларов + топ-6 поддерживающих → EN+ES на **пилларах 1 и 2 только**. Никогда не публиковать вариант локали, линкующий на непереведённого соседа.

**Правило:** каждый пост отгружается с related-posts (без островов) и корректным hreflang до попадания в sitemap.

## 5) Бюджет по фазам (USD, гипотезы)

**Основной путь — DIY-with-AI:**

| Статья | Стоимость | Заметки |
|---|---|---|
| Домен | $10–15/год | apex + www redirect |
| Хостинг (Vercel Hobby/Pro) | $0–20/мес | Pro при нужде в analytics/perf |
| AI (Claude/ChatGPT) | $20–60/мес | контент, keyword-расширение, код |
| Keyword-данные (опц.) | $0–120/мес | сначала бесплатно; 1-мес спринт Ahrefs/Semrush для сида карты, потом отмена |
| Дизайн/шрифты | $0–100 разово | реюз репо; ~1 italic-файл |
| **DIY итого** | **~$40–120/мес + ~$150 разово** | ~**$600–1600 за год 1** |

**Гибрид (выкуп времени / выше качество):**

| Ад-он | Стоимость | Когда стоит |
|---|---|---|
| Правка носителем RU/UK | $0.02–0.05/слово (~$50–150/пиллар) | если твой письменный RU/UK не идеально нативный |
| Фриланс аутрич / digital PR | $300–1000/мес | только после того как контент P2 есть |
| Разовый тех-SEO-аудит | $200–500 | конец P1, до масштабирования ритма |
| **Гибрид год-1** | **~$3000–8000** | быстрее, выше потолок; всё ещё без покупных ссылок |

Дисциплина трат (твоё правило — подтверждать дорогие прогоны): **не тратить на ссылки до того, как есть контент.** Самый дешёвый рычаг (ритм + внутр. перелинковка) — и самый ROI-эффективный в месяцы 0–6.

## 6) Go / Kill чекпоинты

Решать по **опережающим индикаторам**, потому что ранжирование лагает 6–18 мес — судить по выручке на 3 месяце = ложно убить здоровый сайт.

**Месяц 3 — «Машина работает?» (process-gate, не result-gate)**
- ✅ GO если: ≥20 URL в индексе, 0 hreflang/canonical-ошибок, показы GSC **растут** (любые ненулевые), ритм держится (≥2 поста/нед).
- ❌ KILL/PAUSE если: страницы не индексируются (конфиг/остров) или не смог держать ритм. *(Низкий трафик тут — норма, не сигнал убийства.)*

**Месяц 6 — «Google замечает?» (traction-gate)**
- ✅ GO если: non-brand показы растут, ≥1 ЦА-запрос в топ-20, первые клики, ≥1–2 referring domains.
- ⚠️ ITERATE если: только B2B/brand-запросы (старая ловушка OFM) → **перенацелить keyword-карту на ЦА-интент**, не убивать.
- ❌ KILL если: ноль показов при корректной индексации — неверная ниша/гео/спрос.

**Месяц 9 — «Компаундится?» (conviction-gate)**
- ✅ GO (удваивать) если: несколько non-brand в топ-10, клики растут MoM, ≥1 конверсия в Telegram-воронку от органики.
- ❌ KILL если: после 9 мес держанного ритма + ссылок нет non-brand движения и конверсий — домен/гео/оффер не заходит; резать.

**Рамка:** месяцы 3–6 ты оцениваешь **входы** (индексация, ритм, ссылки, верный ЦА-таргет). **Выходы** (ранжирование, клики, воронка) оцениваешь только с месяца 9, против честной кривой **6–18 месяцев**.
