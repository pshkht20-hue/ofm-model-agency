# Фото для блока «Наши модели»

Положите сюда **свои** изображения (лучше **WebP** или **JPG**).

## Рекомендуемые файлы

| Файл | Размер | Где на сайте |
|------|--------|----------------|
| `model-1.webp` | 1200×900 px | Большая карточка слева |
| `model-2.webp` | 900×700 px | Карточка справа сверху |
| `model-3.webp` | 900×700 px | Карточка справа снизу |

Соотношение сторон около **4:3**. Вертикальные или lifestyle-кадры подходят лучше всего.

## Как подключить

1. Добавьте файлы в эту папку (`public/models/`).
2. Откройте `lib/models.ts`.
3. Замените пути, например:

```ts
image: '/models/model-1.webp',
```

4. При необходимости измените имена, цифры дохода и рост (только реальные или допустимые данные).

## Советы

- Можно **не показывать лицо** — кадр со спины, детали, силуэт.
- Одинаковый **цветокор** (тёмный / тёплый) — блок выглядит цельно.
- Удалите файлы `model-*.svg`, когда загрузите свои фото.
