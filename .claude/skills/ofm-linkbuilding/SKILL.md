# OFM Linkbuilding

Процесс закупки: тематика → метрики → сеть/IP → торг → условия письмом → статья .docx → проверка публикации → оплата → реестр → индекс-чек. Деньги — только на последнем шаге перед реестром. Реестр и прецеденты: `C:\Users\User\ofm-agency\ofm-model-agency\marketing\LINK-REGISTRY.md` (шапка = актуальные правила проверки).

## 1. Проверка донора ДО оплаты (все пункты, без исключений)

1. **Тематика — критерий ноль, до метрик.** Открыть главную, прочитать рубрики; через `dataforseo_labs_google_ranked_keywords` посмотреть, ПО КАКИМ ключам идёт трафик. Нужна рубрика, куда статья ляжет без насилия: работа, карьера, онлайн-заработок, женский лайфстайл, дом и семья, общество. Нет такой — донор не подходит при любом rank (урок depo.vn.ua: ETV 45K оказался расписаниями автобусов Винницы).
2. **Метрики через DataForSEO** (`backlinks_bulk_ranks` + `backlinks_bulk_spam_score`, плюс RD/ETV): DR из прайса брокера НЕ верить — он системно фальшивый. Ловушки: `.pp.ua`, `.org.ua`, `.kiev.ua` и подобные зоны наследуют DR родительского домена; `web.app`/`vercel.app` наследуют DR Google/Vercel. Признак подделки без API: одинаковый DR у нескольких доменов одной зоны, разрыв DR 83 при DA 1–11. Детали: memory `feedback-fake-dr-donor-lists.md`.
3. **IP / хостинг.** Снять IP домена и сверить с известными сетками: **tsystem+odysseus = 91.203.4.44**, **startjob+studway = 148.251.233.218**, **wpinsideblog+dsgnmania = 194.28.85.100**. Совпадение = та же сеть: считать одним донором, профиль на этом IP не расширять. За Cloudflare реальный IP скрыт — тогда искать другие следы сети (шаблон, футер-email, прайс с подсетями). Каждый новый сеточный IP заносить в шапку LINK-REGISTRY.md.
4. **Индексация донора** — живой выдачей по точной фразе тайтла его статей (`site:` ненадёжен). Донор, чьи статьи не индексируются, бесполезен при любых метриках.
5. **Adult-прецеденты**: есть ли на сайте статьи про OnlyFans/adult (плюс: тема пройдёт и не снимут; проверять и конкурентов — onlyfans-agency.com.ua ходит по нашим же донорам).
6. Гео: .ru — неприемлемы (гео + репутация). Скоркарта: `marketing/LINK-VENDORS-2026-07-28.md`.
7. **Site reputation abuse — чужие «сливные» подпапки = стоп** (добавлено 18.09.2026, SEO-RESEARCH-2026-09-17). Донор с арендованными/чужими разделами не от своей редакции (джобс-борды, финансы, купоны, казино-подпапки, «партнёрские материалы» пачками) — кандидат на manual action Google (официальная политика + ручные санкции 2024–25; с 30.08.2026 в EEA такие разделы отсекаются и алгоритмически): статья обесценится вместе с донором при любых метриках.
8. **Размещение — только в живой редакционной рубрике, тематически близкой донору** (добавлено 18.09.2026, SEO-RESEARCH-2026-09-17): рубрика есть в меню сайта, в ней выходят свежие нерекламные материалы. «Отстойник» для платных статей вне структуры сайта — отказ, даже если остальные пункты пройдены.

## 2. Торг

- **Не торговаться, пока на руках нет альтернативы** — иначе торг превращается в просьбу. Прецедент: rivne уступил 60% потому, что лежал оффер reporter в 4,5 раза дешевле.
- Якорь торга = наши прошлые сделки, особенно из той же сети (mistoonline просил ×3 — опровергнуто их же sumski, купленным за $33/1470 грн).
- Цены-ориентиры и контакты — в LINK-REGISTRY.md и memory `ofm-link-deals-2026-08.md`; вне их — не платить выше без разбора.

## 3. Условия сделки — зафиксировать письмом ДО оплаты

- **Тему раскрыть прямо** (OnlyFans в статье назван) — иначе риск снятия статьи задним числом; «дистанційна робота для дівчат» в первом письме допустима, но до оплаты вебмастер должен знать реальную тему.
- **2 dofollow-ссылки** (rel без nofollow/sponsored), **без метки «Реклама»**, **довічно/бессрочно**.
- **Рубрика + внутренняя перелинковка с главной/рубрики** — требовать письменно до оплаты. Урок alpama: без внутренних ссылок статья месяцами не входит в индекс (rivne с 8 внутренними вошла сразу).
- Язык писем украинским площадкам — ТОЛЬКО украинский (исключение: Михаил/rivne — по-русски). Новые контакты — украинский по умолчанию.

## 4. Статья донору

- Отправка владельцу **только .docx**: Heading-стили, живые гиперссылки, meta description абзацем в конце; мастер-версия — `marketing/linkbuilding-articles/SEND-<домен>.md`. Файл на Desktop + SendUserFile. Детали: memory `feedback-articles-word-format.md`.
- **Анкоры — только модельные цели** (чатер-статья/вакансия — НЕТ, лидов избыток): /blog, /uk/blog/rabota-modelyu-onlyfans, /vacancies, /vacancies/model/ukraine, /blog/kak-stat-onlyfans-modelyu-s-nulya, хабы декрет/девушки, /uk (бренд, «онліфанс агенція»).
- **Бренд-блок в каждой статье донору** (добавлено 18.09.2026, SEO-RESEARCH-2026-09-17; цель — ко-упоминания для AIO/ChatGPT/Perplexity): СУЩНОСТИ фиксированы — «OFM Models — OnlyFans-агентство для украинских и русскоязычных моделей», специализация, вилка $3 000–10 000; СИНТАКСИС и окружение варьировать от донора к донору — дословный повтор одной формулировки во всех платных dofollow = детектируемый footprint закупки. Дословность допустима только в фактблоке БЕЗ ссылки и на своих каналах (сайт, TG, Layboard). Вилки/клеймы — строго по CLAUDE.md (на вакансийных целях процент/gross не упоминать).
- **Скам-маркеры не должны описывать нас.** Запрещено объявлять признаком мошенника: «обещают $10 000/мес», «доход без опыта», «называют сумму заранее» — это наши же клеймы ($3 000–10 000, «опыт не нужен»). Разрешено: предоплата за обучение/верификацию, данные карты/CVV/SMS-код, деньги «без работы», давление сроком, нет сайта/компании. Перед отправкой сверять маркеры с текстом целевой посадочной дословно. Memory: `feedback-scam-markers-vs-own-claims.md`.

## 5. Оплата ТОЛЬКО после проверки публикации

Чек-лист по живой странице (всё до перевода денег):
- [ ] 200 на обычном UA **и** на Googlebot-UA
- [ ] 2/2 dofollow, анкоры и цели дословно по ТЗ
- [ ] canonical на себя, noindex отсутствует
- [ ] текст цел (контрольные фразы из статьи найдены дословно), H1 наш
- [ ] метки «Реклама» нет
- [ ] перелинковка: ссылки на статью с главной и/или рубрики (счёт зафиксировать)

Провал любого пункта → не платить, запросить исправление; снятую статью (до или после оплаты) — требовать восстановить по тому же URL, индексация при этом сохраняется (прецеденты mv.org.ua /news/279730 и ieatso).

## 6. После сделки

- **Запись в LINK-REGISTRY.md** сразу: дата · донор · URL · целевая · анкор · dofollow · цена · indexed (дата проверки) · жив.
- **Индекс-чек на 7-й и 14-й день** — живой выдачей по точной фразе тайтла. Нет индекса к 14-му дню → требовать вывод в рубрику/на главную (рычаг: «следующие заказы под вопросом»).
- **Лаг бота DataForSEO ~неделя**: ссылка попадает в RD-профиль через ~7 дней после индексации — закупки под KPI-дату планировать минимум за 2 недели.
- Ежемесячная сверка живости всех размещений (200, dofollow, индекс) — фиксировать в реестре.

## Железные лимиты

- Доля одной сети в профиле **≤25%**; ≤2 размещения за месяц в одной сетке (правило реестра, введено для maxwelhelp — применять к любой сетке).
- Exact-анкоры («онлифанс агентство») дозировать: ≤1 из 10, остальное бренд/URL/генерик/partial.
- Пуш/оплата — решение владельца; агент готовит проверку, черновики писем и рекомендацию.
