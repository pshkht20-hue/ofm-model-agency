# OFM Article Gold — статья по золотому стандарту

Скилл = скелет процесса. Детали и доказательства — в первоисточниках, читать ПЕРЕД работой:

## Где живёт статья в коде

- Статья = объект `BlogPost` (TS-массив блоков) в `lib/content/blog/posts/{agency|marketing|money|start|safety}.ts` — файл по категории; типы — `lib/content/blog/types.ts`.
- Блоки: `p / h2 / h3 / ul / table / tip / quote / nav / cases / cta` — рендер в `components/seo/ArticleBody.tsx`. Другие типы не выдумывать.
- Хелперы `lib/content/blog/post-footers.ts`: `LINK.*` (готовые href+label для перелинковки — брать оттуда, не хардкодить), `blogNav(intro, links)`, `blogApplyCta(title, body, options)` (дефолт `/#contact` + GROSS-приписка).
- **href всегда ПЛОСКИЕ** (`/blog/slug`, `/join`) — без локале-префиксов, next-intl добавит сам.
- Локализации = оверлеи `lib/content/blog/locale/{uk,en,es}.ts`: по slug — `title/description/keywords/blocks` целиком.
- Обложки — `lib/content/blog/covers.ts` (`localSrc` И `remoteSrc` = `/blog/covers/{slug}.jpg`, 1600×900).

## 1. Pre-flight (обязательный, ДО текста) — стандарт §1

1. Объёмы и орфография ключа — DataForSEO/GSC («чатер» 480/мес, не «чаттер» 0). Форму слова проверять перед каждым тайтлом.
2. Живая выдача топ-3: интент и формат (гайд/листикл/история) — формат копируем, контент нет.
3. Найти вопрос читательницы, на который топ-3 не ответили — секция с ответом = дифференциатор.
4. Место в кластере (sequencing): пишем только в кластер с ранжированием, с планом перелинковки → хаб, → 2–3 соседа, → деньги-страница (/join или вакансия).
5. Подготовить **10–15 собственных цифр** (наши статистики, сроки, анонимные кейсы) — главный предиктор оригинальности.
6. Приоритет тем — jobs/роль-кластер (интент решает: CTR 4–6% vs <1% у «что такое» под AI Overview).
7. **Fan-out-подзапросы** (Gemini/ChatGPT/Perplexity) — третий источник H2/FAQ ПОСЛЕ PAA/GSC: закрывать секциями, НЕ отдельными страницами (fan-out-страницы = scaled content abuse); списки от LLM фильтровать через PAA/GSC; объём не раздувать — стандарт §1.6 (18.09.2026).
8. **Анти-каннибализация**: прежде чем новая страница — проверить, не перенастроить ли существующую (GSC 4–15). Слияние/прунинг/301 = скелет, ТОЛЬКО с подтверждения владельца — стандарт §1.7 (18.09.2026).

## 2. Тайтл, дескрипшен, лид — стандарт §2–3

- Роль-статьи: «[точный ключ]: кто это, сколько платят и как стать», ≤55–60 знаков (CTR ×11). How-to: число шагов в тайтле.
- Дескрипшен — стиль джоб-объявления: «удалённо, можно без опыта, старт за 7–14 дней, заявка анонимна, 18+». Без кликбейта.
- **Answer-first**: первое предложение статьи = прямой ответ с ключом; под каждым H2 первые 40–60 слов — самодостаточный ответ. Бренд внутри цитируемого блока («Агентство OFM платит…», не безлично).
- В сниппет — то, чего нет в AI Overview: вилки денег, путь, сроки.
- **Сущность главного запроса — в тайтле + лиде + FAQ. При рерайте сущности только ДОБАВЛЯТЬ, не убирать** (урок 07.09: рерайт убрал «OF model» из title/лида/FAQ и уронил №1-запрос сайта).
- **Flow рефреша начинается с выгрузки, ДО любых правок текста** (стандарт §1.8 + §8.5, 18.09.2026): GSC-запросы страницы → список защищённых сущностей; дописывать НОВЫМИ секциями-ответами под запросы без ответа, не вписыванием вхождений; вакансии из рефреша исключены. Во время раската core update — freeze выводов и откатов (стандарт §8.7).
- Опинионный квалификатор листиклов и год в тайтле — только по правилам стандарта §2 (год = конвейер рефреша §8.5, раскат с замером CTR).

## 3. Скелет статьи — стандарт §3–4

- H2/H3 = живые вопросы ЦА из PAA/GSC; **страхи — полноценными H2** в порядке возникновения (анонимность → безопасность → «что скажут» → легальность).
- Таблица денег: 2 колонки, 3–5 строк («уровень → деньги/мес») — блок `table`.
- Блок `cases` (тизер скринов + NET) и кликабельный t.me — в каждой денежной статье; `tip` — практические вставки; `quote`-соцпруф с цифрой в разрешённой вилке вплотную к CTA.
- FAQ **4–6 вопросов** дословно из живых запросов, включая неудобные; ответ 2–4 предложения с цифрой. НЕ 20.
- **3 CTA одной цели на глубинах ~25% / ~60% / конец**, после ответа секции: середина — мягкий (канал t.me/ofmmAgency), конец — прямой («написать менеджеру», deep-link без форм). Мост на /calculator перед главным CTA.
- ~7 контекстных `nav`-блоков по ходу текста (хелперы `blogNav` + `LINK`), не копить ссылки в футере.
- Объём 15–25K знаков; болд 2–5 на экран; E-E-A-T первым лицом; семантические вариации вместо повторов ключа.
- Листиклы: модульный каркас пункта — H3: описание → вилка денег → требования → плюсы/минусы, цифры в первых строках H3 (в сниппет); каркас фиксирован, наполнение варьировать; /vacancies* не касается — стандарт §3.12 (18.09.2026).
- **Внешние источники: 2–3 трастовые стабильные ссылки** (help-страницы OnlyFans, гос-источники Украины) — не конкуренты, не новостные, без разоблачений/негатива об агентствах — стандарт §3.13. **UGC-врезки «что говорят модели»** — только РЕАЛЬНЫЕ анонимизированные цитаты (согласие либо глубокая анонимизация), синтез ЗАПРЕЩЁН, цифры в $15K–$50K — стандарт §3.14 (18.09.2026).
- Автор-байлайн + `author` в BlogPosting — ТОЛЬКО после решения владельца по персоне; псевдоним лишь с реальным опытом, консистентный на всех языках — стандарт §3.15.

## 4. Железные правила денег и подачи (нарушение = статья не выходит)

- Процент: «модель получает **20–30% от gross**» — всегда С реинвест-обоснованием; доход-клейм только **$15K–$50K** (не $100K).
- Контракты с агентством НЕ упоминать (подача: старт без бюрократии, свобода выйти). НЕ писать «не отдавайте доступ агентству» и «работаем без лица».
- На /vacancies* — витрина: без процента/gross/реинвеста/калькулятора; вилки $3 000–10 000/15 000/20 000. Честный слой — только блог и /join.
- Запрещённые страны (РФ/РБ/Казахстан, полный список `docs\BANNED-COUNTRIES-2026-07.md`) — не упоминать, не таргетить.
- Fansly/LoyalFans — только в статьях блога, никогда на главной/join/вакансиях. Полный список табу — стандарт §9.

## 5. Оверлеи UK/EN/ES

- Оверлей = полное зеркало статьи в `locale/{uk,en,es}.ts`: title/description/keywords/blocks, структура блоков 1:1 с RU.
- **Зеркальность цифр RU↔UK** (и всех локалей): суммы, сроки, вилки идентичны — расхождение = баг.
- UK: апостроф **ʼ** (пʼять, звʼязок), деруссификация — вычищать русизмы и кальки в первую очередь; ключи украинские («онліфанс…»).
- EN: не калькировать с русского, сущность запроса (см. урок 07.09). ES: формат сумм **$3.000** (точка-разделитель), нейтральный испанский, обращение **tú**.
- Keywords оверлея — из локальных запросов (DataForSEO по гео/языку), не перевод RU-списка.
- **Режим «EN-статья» — ТЕСТ на части статей с замером** (blueprint aruna, стандарт §3.4, 18.09.2026): опинионные topic-H2, вопросные формулировки — в FAQ; CTA каждые ~800–1000 слов (совместимо с 3 CTA); байлайн-соцпруф только реальной цифрой, одобренной владельцем; внутренние ссылки только в свой EN-кластер. Стандарт целиком не переписывать.
